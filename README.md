# 温州里世界

门与门禁的三维模型在线预览。支持旋转、缩放、平移和原文件下载。

在线访问：https://github.xialiwei.com/wenzhou-inner-world/

原始文件保存在 models/，未修改。Three.js 0.170.0 及加载器本地托管，许可证见 vendor/three/LICENSE。

本地预览：`python -m http.server 8766`
